# Data Directory

Place your CSV or Excel patient dataset here, or use the synthetic dataset generated by the application.

## Synthetic Dataset

The application generates a synthetic dataset with the following schema:

| Column | Type | Description |
|---|---|---|
| patient_id | string | Unique patient identifier |
| age | numeric | Age at diagnosis (years) |
| sex | categorical | Male / Female |
| stage | categorical | Disease stage: I / II / III / IV |
| subtype | categorical | Disease subtype: A / B / C |
| treatment | categorical | Surgery / Chemo / Radiation / Combined |
| follow_up_months | numeric | Follow-up duration (months) |
| event | binary | 1 = event occurred, 0 = censored |
| survival_5yr | binary | 1 = survived 5 years, 0 = did not |
| comorbidity_score | numeric | Comorbidity index 0–4 |
| region | categorical | North / South / East / West |

**This synthetic data is not real clinical data and must not be presented as such.**

## Real Dataset Requirements

To use a real dataset, upload a CSV or Excel file with at minimum:
- A follow-up duration column (non-negative numeric)
- An event indicator column (binary: 0/1)
- At least one grouping variable (categorical)
